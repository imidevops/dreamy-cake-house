Owner Login

This panel commits changes straight to the site's cake data on GitHub. Paste a GitHub Personal Access Token to continue — it's stored only in this browser and sent only to GitHub.

  1. Go to github.com/settings/personal-access-tokens/new
  2. Create a fine-grained token scoped to only the dreamy-cake-house repository
  3. Under Repository permissions, set Contents: Read and write
  4. Generate it, copy it, and paste it below
