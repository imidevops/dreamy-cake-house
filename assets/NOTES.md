# /assets

Static assets. `img/legacy/` and `img/modern/` hold uploaded cake photos, one file per cake, named `<cake-id>.<ext>` (e.g. `img/legacy/legacy-victoria-sponge.jpg`).

These are written by the admin panel ([/pages/admin/NOTES.md](../pages/admin/NOTES.md)), not by hand — the owner uploads a photo per cake there, which commits it here via the GitHub API and sets that cake's `image` field in `/data/*.json`. A cake with no uploaded photo (`image: null`) falls back to a CSS gradient + emoji placeholder generated by `cakeThumbStyle(id)` in [/shared/utils.js](../shared/utils.js) — see `cakeThumbMarkup()` in the same file for how every page decides which to render.
