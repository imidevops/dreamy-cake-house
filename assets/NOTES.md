# /assets

Static assets (images, icons) not covered by CSS-generated placeholders.

Currently empty — the site has no real product photography yet, so every cake thumbnail is a CSS gradient + emoji placeholder generated by `cakeThumbStyle(id)` in [/shared/utils.js](../shared/utils.js). Drop real photos in `/assets/img/<category>/` when available, add an `images: []` field to the relevant cake objects in `/data/*.json`, and update the card-rendering functions in each page's JS ([/pages/home](../pages/home/NOTES.md), [/pages/legacy-cakes](../pages/legacy-cakes/NOTES.md), [/pages/modern-cakes](../pages/modern-cakes/NOTES.md), [/pages/cake-detail](../pages/cake-detail/NOTES.md), [/pages/gallery](../pages/gallery/NOTES.md)) to render `<img>` instead of the placeholder div.
